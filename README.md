# XSLT: группировка по уникальным значениям

Задание «Претендуем на звание Мастера XSLT».

XML со списком товаров (`item`) преобразуется в HTML с двумя группировками:

1. компании по городам;
2. товары по компаниям.

## Файлы

- `data.xml` — исходный XML
- `transform.xsl` — XSLT 1.0 stylesheet
- `result.html` — результат преобразования

## Как работает

Используется группировка методом Мюнха через `xsl:key`:

- `items-by-city` — товары по городу (`@city`);
- `items-by-org` — товары по компании, ключ составной: `concat(@city, '|', @org)`.

Составной ключ нужен, потому что «ООО Светлана» есть и в Москве, и в Петербурге.
Это разные компании, и по одному `@org` они бы слились в одну группу.

Внутри компании товары сортируются по названию (`xsl:sort`).

## Запуск

```bash
xsltproc transform.xsl data.xml > result.html
```

Или открыть `data.xml` в браузере через локальный сервер (`python -m http.server`),
в нём подключён `transform.xsl`.
